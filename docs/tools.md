# Tools

See [README — Tools](https://github.com/Ricardo-M-L/anthrogo#tools).

anthrogo ships 20+ built-in tools that the model can invoke during a session.

## Built-in tools (partial list)

| Tool | Description |
|---|---|
| `Bash` | Execute shell commands in a sandboxed environment |
| `Read` | Read a file from disk |
| `Write` | Write content to a file |
| `Edit` | Targeted string replacement in a file |
| `Grep` | Search files by regex pattern |
| `Git` | Git operations |
| `WebFetch` | Fetch a URL and return its content |
| `WebSearch` | Multi-backend web search |
| `SymbolSearch` | Search symbols across the codebase |
| `ContainerExec` | Execute commands inside a container |
