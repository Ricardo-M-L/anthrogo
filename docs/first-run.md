# First run

See [README](https://github.com/Ricardo-M-L/anthrogo#first-run).

## Basic usage

```bash
export ANTHROPIC_API_KEY=sk-ant-...
anthrogo
```

anthrogo opens an interactive TUI session. Type a prompt and press Enter. Use **F2** to cycle panes, **Ctrl+C** to quit.

## Slash commands

Type `/help` inside the TUI to list available slash commands. See [Slash commands reference](reference/commands.md) for the full list.
