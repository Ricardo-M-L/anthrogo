# CLI flags

See [README — CLI flags](https://github.com/Ricardo-M-L/anthrogo#cli-flags).

## Synopsis

```
anthrogo [flags] [prompt]
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `--version` | — | Print version and exit |
| `--config` | `~/.anthrogo/settings.yaml` | Path to config file |
| `--provider` | `anthropic` | Provider to use |
| `--model` | provider default | Model name |
| `--no-color` | false | Disable color output |
| `--debug` | false | Enable debug logging |
| `--session` | — | Resume a specific session by ID |
