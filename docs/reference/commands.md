# Slash commands

See [README — Slash commands](https://github.com/Ricardo-M-L/anthrogo#slash-commands).

Slash commands are typed directly in the TUI prompt.

## Built-in commands

| Command | Description |
|---|---|
| `/help` | List available commands |
| `/compact` | Summarize old context |
| `/cost` | Show session token usage and cost |
| `/sessions list` | List saved sessions |
| `/sessions show <id>` | Show session transcript |
| `/sessions search <q>` | Search sessions |
| `/history` | Show recent prompts |
| `/history search <q>` | Search input history |
| `/plugin install <src>` | Install a plugin |
| `/plugin list` | List installed plugins |
| `/skill <name>` | Run a skill |
| `/subagent <tasks...>` | Dispatch concurrent subagents |
| `/kairos <task>` | Dispatch remote KAIROS task |
| `/mcp list` | List connected MCP servers |
| `/quit` | Exit the session |
