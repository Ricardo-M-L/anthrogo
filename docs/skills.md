# Skills

See [README — Skills](https://github.com/Ricardo-M-L/anthrogo#skills).

Skills are reusable prompt fragments that the model can invoke via slash commands. They live in `~/.anthrogo/skills/` as Markdown files.

## Usage

```
/skill <name> [args]
```

## Creating a skill

Create `~/.anthrogo/skills/my-skill.md`:

```markdown
# my-skill

Do X when asked about Y.
```
